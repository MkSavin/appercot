# Getting started

Follow these pages in order for a local installation. Use the deployment section instead when the target is a public server.

1. [Requirements](requirements.md): choose Bun or Docker and prepare credentials.
2. [Local development](local-development.md): install dependencies and start the web client and API.
3. [Your first bot](first-bot.md): create a bot, connect the SDK, and handle a command.

After the first command works, continue with [bot development](../bots/index.md) or [testing](../testing/index.md).
