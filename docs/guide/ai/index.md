# AI assistants

This guide is written in English and organized into small, linked pages so coding assistants can retrieve a focused answer instead of the whole repository.

- [Context7 setup](context7.md): configure the client, publish the source, query the right library, and refresh documentation.
- [Effective prompts](prompting.md): give the assistant a deployment context and ask for verifiable public APIs.

For changes to Appercot itself, assistants should also read the repository root `AGENTS.md` and the relevant `.agents` pages. Those documents contain invariants and source-level rules that are intentionally separate from the public usage guide.
